Основной файл, собирающий информацию в этой папке — `check_all.g`. Но 
выводит результаты в два файла: `fixedpoint_main.txt`, 
`fixedpoint_results.txt`. В первом из них 
информация в "машиночитаемом" формате, а во втором — в 
"человекочитаемом".

Также можно запустить `analyze_gap.py` — он для каждой группы, каждого 
простого и каждого нетривиального неприводимого характера выведет 
`False`, если появляется лишнее ребро (и само ребро перед этим), а 
иначе выведет `True`, что будет означать, что представление, 
соответствующее этому характеру, возможно.

У меня сейчас получается, что возможно только `p1 = 2` для M<sub>22</sub> и 
Aut(M<sub>22</sub>). Для остальных групп и простых `p1` либо все характеры не 
подходят, либо таблица Брауэра не вычисляется.

Проблема с невычисляющейся таблицей Брауэра есть только для Fi<sub>24</sub>'.
При этом для всех `p1` кроме 2, 3 работает лемма через подгруппы Фробениуса.
Также для `p1 = 3` можно посмотреть на Брауэровы характеры только для 
подгруппы Fi<sub>24</sub>' — Fi<sub>23</sub> и окажется, что уже для неё
нет ни одного подходящего.

Таким образом, осталась проблема только с `p1 = 2` и Fi<sub>24</sub>', 
которую я не знаю, как решать.
