# Директории проекта
В проекте есть 4 директории:

- `cands` и `graphs`: в обеих директориях хранятся картинки графов, нарисованные программой. В первой из них — есть 4 папки на каждую из "нетривиальных" групп, где хранятся графы групп-кандидатов на S<sub>1</sub>.
- `draw`: здесь хранятся файлы, которые используются для отрисовки графов.
- `p1_in_K`: здесь написан код для проверки принадлежности p<sub>1</sub> ∈ π(K).

Далее — более подробно про `draw` и `p1_in_K`.

## Директория `draw`

### Файл `print_group_orders.g`

В этом файле написана программа на `gap`, в которой считается, что изначальна задана группа `G`. На выходе эта программа печатает сначала "Size: " и размер группы, а потом "Orders: ", после чего список порядков элементов из всех классов смежности через пробел.

### Файл `saved_info.py`

В этом файле хранится `graphs` — словарь, в котором по имени группы лежит пара из списка простых делителей порядка группы и списка рёбер графа Грюнберга-Кегеля. Есть функция `clear_name`, с помощью которой разные названия одной группы приводятся к одному и тому же. Например, `M22.2` и `Aut(M22)` будут считаться одной группой с названием `Aut(M22)`.

### Файл `create_graph.py`

В этом файле есть основная функция — `build_and_draw`, которая создаёт граф в виде двух списков — вершин и рёбер — а потом просит другую функцию из файла `show_gk.py` нарисовать этот граф. При этом есть 2 случая:
- Если вершины и рёбра для текущей группы уже ранее создавались, то они сохранены в `saved_info.py` и их можно просто оттуда взять.
- Иначе нужно с нуля создать граф. Для этого используется программа на `gap` из файла `print_group_orders.g`.

### Файл `show_gk.py`

Здесь написана функция, которая по названию файла, а также спискам вершин и рёбер графа отрисовывает его и сохраняет в файл.

### Файл `main.py`

Это файл, где написаны основные функции, которые можно вызывать для отрисовки графов простых групп и их автоморфизмов.

## Директория `p1_in_K`

### Файлы с расширением `.g`

Они используются для того, чтобы для различных групп перебирать все Брауэровы характеры и проверять, для каких характеров из таблицы Брауэра для p<sub>1</sub> и какиех p<sub>2</sub> верно, что существует элемент порядка p<sub>2</sub>, у которого C<sub>K</sub>(G) нетривиально.

### Файл `fixedpoint_main.txt`

Это вывод `gap`-файлов в машиночитаемом формате, который в дальнейшем используется для `analyze_gap.py`.
